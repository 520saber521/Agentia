# records/：AI 协作复盘记录

本目录保留 AgentHub 项目中的真实 AI 协作痕迹，包括决策过程、踩坑记录、度量数据和后续待办。

## 命名规范

```text
YYYYMMDD-<标签>.md
```

- `YYYYMMDD`：记录对应的日期（通常是协作发生的当天）。
- `<标签>`：简短英文标识，描述记录主题。
  - `W1`, `W2-D1`, `W4-Diff` — Sprint + 日期 / Feature 编号。
  - `D0-archive-v1` — 特殊事件（归档、重构启动等）。
  - 使用小写、连字符分隔、不超过 4 个词。

## 记录模板

新建记录时复制以下模板，填写各节。标注 `(可选)` 的节按需保留或删除。

```markdown
# YYYYMMDD · <标签> · <一句话标题>

> 周期：<日期范围或单日>
> 操作员：<谁在主控>
> 主协作 Agent：<Cursor/Claude Code 内的哪个模型>
> 对应 SPEC：[<Feature 编号>](../SPEC.md#<锚点>)

---

## 1. 本次交付

| ... | ... | ... | ... |

## 2. 关键决策

### 决策 N · <决策名称>

**背景**：<为什么需要做决策>

**选择**：<做了什么选择>

记录操作员与 AI 的关键交互回合：操作员的 prompt 意图、AI 的候选方案、操作员的选择和打回、最终结果。
```

## 从记录到规则的提炼路径

```text
记录中的踩坑 / 决策
    ↓  提炼为硬约束
rules/*.mdc 中的规则条目
    ↓  规则必须标注来源
records/ 中保留原始上下文
    ↓  同类问题第二次出现
skills/*.md 中的可复用步骤
```
